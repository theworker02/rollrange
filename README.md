# rollrange

Roll HTML/Markdown range fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/rollrange/

## Install / run

```bash
git clone https://github.com/theworker02/rollrange.git
cd rollrange
node src/cli.js
node --test
```
